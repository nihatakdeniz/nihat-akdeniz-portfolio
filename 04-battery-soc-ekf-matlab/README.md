# Battery State of Charge Estimation

State of Charge (SOC) estimation using a Thevenin equivalent circuit and Extended Kalman Filter (EKF). Genetic Algorithm and Ant Colony Optimization were used for parameter optimization. Reported RMSE: 0.2491.

## Contents

- `src/`: MATLAB scripts

## Tools

MATLAB/Simulink; EKF; Genetic Algorithm; Ant Colony Optimization.
